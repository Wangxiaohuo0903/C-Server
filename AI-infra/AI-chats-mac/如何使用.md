# AI Chat Server - Mac 版本使用说明

## 🚀 快速启动

### 方法 1：使用启动脚本（推荐）

```bash
cd /Users/xiaohuo/Documents/Code/项目一代码/AI-infra/AI-chats-mac
./start_server.sh
```

### 方法 2：手动启动

```bash
cd /Users/xiaohuo/Documents/Code/项目一代码/AI-infra/AI-chats-mac/build

```

## 📋 启动后会看到什么

1. **模型加载过程**（约 5-10 秒）
   - TinyLlama 1.1B 模型加载信息
   - Metal GPU 初始化（Apple M1 Max）
   - 606MB GPU 显存分配

2. **成功提示**
   ```
   [Model] loaded ok: ../../models/tinyllama-q4.gguf
   [Server] listening on port 8080
   ```

## 🌐 访问网页界面

打开浏览器访问以下地址：

- **登录页面**: http://localhost:8080/login.html
- **注册页面**: http://localhost:8080/register.html
- **主页（自动跳转）**: http://localhost:8080/

## ✨ 新功能：ChatGPT 风格多会话界面

### 界面特点

1. **左侧边栏**
   - 显示所有聊天会话
   - "新对话" 按钮创建新会话
   - 每个会话显示标题和预览
   - 点击会话可切换
   - 鼠标悬停显示删除按钮

2. **主聊天区域**
   - 汉堡菜单按钮切换侧边栏
   - 显示当前会话标题
   - 消息列表（支持滚动）
   - 底部输入框发送消息

3. **暗色主题**
   - 深色背景，护眼舒适
   - 与 ChatGPT 相似的配色方案

### 使用技巧

- **创建新对话**: 点击侧边栏顶部的 "新对话" 按钮
- **切换对话**: 点击侧边栏中的任意会话
- **删除对话**:
  - 鼠标悬停在会话上，点击出现的 X 按钮
  - 或点击聊天区域右上角的删除按钮删除当前会话
- **自动保存**: 所有对话自动保存，刷新页面后依然存在
- **自动标题**: 第一条消息自动成为会话标题

## 🛑 停止服务器

### 方法 1：终端中按 Ctrl+C

### 方法 2：命令行停止
```bash
pkill ai_infra_server_mac
```

### 方法 3：查找并杀死进程
```bash
# 查找进程
ps aux | grep ai_infra_server_mac

# 杀死进程（替换 PID 为实际进程号）
kill <PID>
```

## 📊 系统要求

- **操作系统**: macOS (Apple Silicon)
- **芯片**: Apple M1/M2/M3 系列
- **内存**: 至少 8GB RAM

## 🆘 常见问题

### 1. 端口 8080 被占用
```bash
# 查看占用端口的进程
lsof -i :8080

# 停止旧服务器
pkill -9 ai_infra_server_mac
```

### 2. 模型文件找不到
确保模型文件在正确位置：
```bash
ls ../../models/tinyllama-q4.gguf
```

### 3. UI 页面 404
确保在 build 目录下运行，并检查 UI 文件：
```bash
ls ../../UI/*.html
```

### 4. Metal GPU 未启用
如果看到 CPU 推理而非 Metal GPU，检查：
- 是否为 Apple Silicon Mac
- 是否使用最新的编译版本

## 🔄 重新编译

```bash
rm -rf build

cmake ..

```

## 📝 技术说明

- **HTTP 服务器**: 使用 kqueue（macOS 原生 I/O 多路复用）
- **AI 模型**: TinyLlama 1.1B Q4 量化版本（606MB）
- **GPU 加速**: Apple Metal 框架
- **数据库**: SQLite（用户和聊天记录）
- **前端**: 原生 HTML/CSS/JavaScript
- **并发**: C++ 线程池处理多个请求
