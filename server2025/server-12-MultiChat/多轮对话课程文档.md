# Server-12 课程文档：多轮对话与会话管理

## 铺垫概念

### 1. 对话系统的演进
- **单轮问答**（Server-11）：
  ```
  用户: "什么是AI？"
  AI: "人工智能是..."

  用户: "它有什么应用？"
  AI: "我不知道你在说什么。"  ← 没有上下文
  ```

- **多轮对话**（Server-12）：
  ```
  用户: "什么是AI？"
  AI: "人工智能是..."

  用户: "它有什么应用？"
  AI: "AI的应用包括..."  ← 记住了"AI"的上下文
  ```

### 2. 对话状态管理
- **无状态（Stateless）**：
  - 每个请求独立处理
  - 服务器不保存任何用户信息
  - 类比：记忆被清除的机器人

- **有状态（Stateful）**：
  - 服务器记住用户的对话历史
  - 每次回复都考虑之前的对话
  - 类比：有记忆的人类对话

### 3. Session（会话）概念
- **定义**：一次完整的用户交互过程，包含多轮对话。
- **类比**：
  - 餐厅：一次就餐从进门到结账
  - 网页：从登录到登出的整个过程
  - AI聊天：一个对话窗口的所有消息

**Session 的生命周期**：
```
创建 Session
    ↓
添加消息1（用户: "你好"）
    ↓
添加消息2（AI: "你好！"）
    ↓
添加消息3（用户: "天气如何"）
    ↓
添加消息4（AI: "今天晴天..."）
    ↓
...（更多对话）
    ↓
删除 Session（关闭对话）
```

## 为什么需要 SessionManager

### Server-11 的痛点

#### 问题1：无法多轮对话
```cpp
// Server-11 的实现
std::string generate(const std::string& prompt, int max_tokens);
```

每次调用都是独立的，无法记住之前说了什么：
```
第1次: generate("我叫Alice")  → "很高兴认识你，Alice！"
第2次: generate("我叫什么？")  → "我不知道你的名字。"  ← 遗忘了
```

#### 问题2：无法管理多个用户
```
用户A: "我喜欢篮球"
用户B: "我喜欢足球"

问题：如何区分A和B的对话？
      如何避免A和B的对话混在一起？
```

#### 问题3：无法实现 ChatGPT 风格的 UI
ChatGPT 的核心特性：
- 左侧显示多个对话列表
- 点击不同对话查看历史
- 可以新建对话、删除对话

Server-11 无法实现这些功能。

### SessionManager 的解决方案

```cpp
class SessionManager {
    // 为每个用户/对话创建独立的 Session
    std::unordered_map<std::string, Session> sessions_;

    // 每个 Session 包含：
    // - session_id：唯一标识符
    // - history：对话历史记录
    // - title：对话标题
    // - timestamps：创建时间、最后活跃时间
};
```

**核心功能**：
1. **Session 创建/删除**：管理对话的生命周期
2. **消息历史存储**：记录每轮对话的 user/assistant 消息
3. **上下文拼接**：将历史拼接成完整 prompt
4. **多用户隔离**：每个用户有独立的 session_id

## 核心数据结构详解

### 1. Message - 单条消息

```cpp
struct Message {
    std::string role;       // "user" 或 "assistant"
    std::string content;    // 消息内容
    long long timestamp;    // 时间戳（毫秒）

    Message(const std::string& r, const std::string& c)
        : role(r), content(c) {
        // 获取当前时间戳
        timestamp = std::chrono::duration_cast<std::chrono::milliseconds>(
            std::chrono::system_clock::now().time_since_epoch()
        ).count();
    }
};
```

**设计要点**：
- `role`：区分用户消息和AI回复
- `content`：实际的文本内容
- `timestamp`：用于排序、过期检测、统计分析

**示例**：
```cpp
Message msg1("user", "你好");
Message msg2("assistant", "你好！有什么可以帮助你的吗？");

// msg1.timestamp = 1704067200000 (2024-01-01 00:00:00)
// msg2.timestamp = 1704067202000 (2024-01-01 00:00:02)
```

### 2. Session - 会话结构

```cpp
struct Session {
    std::string session_id;              // 会话ID（唯一标识）
    std::vector<Message> history;        // 对话历史
    long long created_at;                // 创建时间
    long long last_active;               // 最后活跃时间
    std::string title;                   // 会话标题

    // 添加消息到历史
    void addMessage(const std::string& role, const std::string& content) {
        history.emplace_back(role, content);
        updateLastActive();

        // 自动设置标题（第一条用户消息的前30字符）
        if (title == "New Chat" && role == "user" && !content.empty()) {
            title = content.substr(0, std::min((size_t)30, content.length()));
            if (content.length() > 30) {
                title += "...";
            }
        }
    }

    // 获取完整上下文（拼接所有历史）
    std::string getFullContext() const {
        std::string context;
        for (const auto& msg : history) {
            if (msg.role == "user") {
                context += "User: " + msg.content + "\n";
            } else {
                context += "Assistant: " + msg.content + "\n";
            }
        }
        return context;
    }

    // 获取最近N轮对话
    std::string getRecentContext(int n_turns = 5) const {
        std::string context;
        int start_idx = std::max(0, (int)history.size() - n_turns * 2);

        for (size_t i = start_idx; i < history.size(); ++i) {
            if (history[i].role == "user") {
                context += "User: " + history[i].content + "\n";
            } else {
                context += "Assistant: " + history[i].content + "\n";
            }
        }
        return context;
    }
};
```

**核心方法**：

#### addMessage() - 添加消息
```cpp
Session session("session_123");
session.addMessage("user", "我叫Alice");
session.addMessage("assistant", "你好，Alice！");
session.addMessage("user", "我叫什么名字？");

// session.history = [
//   {role: "user", content: "我叫Alice", ...},
//   {role: "assistant", content: "你好，Alice！", ...},
//   {role: "user", content: "我叫什么名字？", ...}
// ]
```

#### getFullContext() - 获取完整上下文
```cpp
std::string context = session.getFullContext();
// 输出:
// "User: 我叫Alice\n"
// "Assistant: 你好，Alice！\n"
// "User: 我叫什么名字？\n"
```

这个上下文会被拼接到新的 prompt 中，让 AI 能"记住"之前的对话。

#### getRecentContext() - 限制上下文长度
```cpp
// 只获取最近5轮对话（10条消息）
std::string context = session.getRecentContext(5);
```

**为什么要限制？**
- 避免 prompt 超出模型的 `n_ctx` 限制（如 2048 tokens）
- 过长的上下文会导致推理变慢
- 最近的对话通常更相关

### 3. SessionManager - 会话管理器

```cpp
class SessionManager {
private:
    std::unordered_map<std::string, Session> sessions_;  // session_id → Session
    std::mutex mutex_;                                   // 线程安全保护
    std::random_device rd_;                              // 随机数生成器
    std::mt19937 gen_;                                   // Mersenne Twister引擎

public:
    // 创建新会话
    std::string createSession();

    // 添加消息到会话
    bool addMessage(const std::string& session_id,
                   const std::string& role,
                   const std::string& content);

    // 获取会话的完整上下文
    std::string getSessionContext(const std::string& session_id, int n_turns = 5);

    // 获取会话列表（用于前端显示）
    std::string getSessionList();

    // 删除会话
    bool deleteSession(const std::string& session_id);

    // 检查会话是否存在
    bool sessionExists(const std::string& session_id);
};
```

## 核心方法实现详解

### 1. createSession() - 创建新会话

```cpp
std::string SessionManager::createSession() {
    std::lock_guard<std::mutex> lock(mutex_);  // 线程安全

    // 生成唯一的 session_id
    std::string session_id = generateSessionId();

    // 创建新 Session 并加入 map
    sessions_[session_id] = Session(session_id);

    std::cout << "[SessionManager] Created session: " << session_id << "\n";
    return session_id;
}

// 生成 session_id 的实现
std::string SessionManager::generateSessionId() {
    // 使用随机数 + 时间戳确保唯一性
    std::uniform_int_distribution<> dis(0, 15);
    std::stringstream ss;

    // 生成 16 位十六进制字符串（如 "a3f5d8b2c1e9f4a6"）
    for (int i = 0; i < 16; ++i) {
        ss << std::hex << dis(gen_);
    }

    return ss.str();
}
```

**生成的 session_id 示例**：
```
"a3f5d8b2c1e9f4a6"
"7b2e9f1c4d8a3e5f"
"c1f9a3e5b2d4f8e7"
```

**唯一性保证**：
- 16 位十六进制 = 2^64 种可能
- 碰撞概率极低（生日悖论：约需 2^32 个 session 才可能碰撞）

### 2. addMessage() - 添加消息

```cpp
bool SessionManager::addMessage(
    const std::string& session_id,
    const std::string& role,
    const std::string& content
) {
    std::lock_guard<std::mutex> lock(mutex_);

    // 检查 session 是否存在
    auto it = sessions_.find(session_id);
    if (it == sessions_.end()) {
        std::cerr << "[SessionManager] Session not found: " << session_id << "\n";
        return false;
    }

    // 添加消息到 session
    it->second.addMessage(role, content);

    std::cout << "[SessionManager] Added " << role << " message to session "
              << session_id << "\n";
    return true;
}
```

**使用示例**：
```cpp
SessionManager sm;
std::string session_id = sm.createSession();

sm.addMessage(session_id, "user", "你好");
sm.addMessage(session_id, "assistant", "你好！有什么可以帮助你的吗？");
```

### 3. getSessionContext() - 获取上下文

```cpp
std::string SessionManager::getSessionContext(
    const std::string& session_id,
    int n_turns
) {
    std::lock_guard<std::mutex> lock(mutex_);

    auto it = sessions_.find(session_id);
    if (it == sessions_.end()) {
        return "";  // session 不存在
    }

    // 使用 Session 的 getRecentContext() 方法
    return it->second.getRecentContext(n_turns);
}
```

**完整的推理流程**：
```cpp
// 1. 用户发送新消息
sm.addMessage(session_id, "user", "我叫什么名字？");

// 2. 获取上下文（包含历史）
std::string context = sm.getSessionContext(session_id);
// context = "User: 我叫Alice\n"
//          "Assistant: 你好，Alice！\n"
//          "User: 我叫什么名字？\n"

// 3. 添加新的 prompt
std::string full_prompt = context + "Assistant:";

// 4. 调用 AI 推理
std::string ai_reply = ModelManager::instance().infer(full_prompt, 64);

// 5. 将 AI 回复也加入历史
sm.addMessage(session_id, "assistant", ai_reply);
```

### 4. getSessionList() - 获取会话列表

```cpp
std::string SessionManager::getSessionList() {
    std::lock_guard<std::mutex> lock(mutex_);

    // 构建 JSON 数组
    std::stringstream json;
    json << "[";

    bool first = true;
    for (const auto& [session_id, session] : sessions_) {
        if (!first) json << ",";
        first = false;

        json << "{"
             << "\"session_id\":\"" << session_id << "\","
             << "\"title\":\"" << session.title << "\","
             << "\"message_count\":" << session.history.size() << ","
             << "\"last_active\":" << session.last_active
             << "}";
    }

    json << "]";
    return json.str();
}
```

**输出示例**：
```json
[
  {
    "session_id": "a3f5d8b2c1e9f4a6",
    "title": "我叫Alice",
    "message_count": 4,
    "last_active": 1704067200000
  },
  {
    "session_id": "7b2e9f1c4d8a3e5f",
```

## Router 集成：多轮对话 API

### 1. 创建会话接口

```cpp
addRoute("POST", "/api/sessions/new", [&sessionManager](const HttpRequest& req) {
    // 创建新会话
    std::string session_id = sessionManager.createSession();

    // 返回 session_id
    HttpResponse resp;
    resp.setStatusCode(200);
    resp.setHeader("Content-Type", "application/json");
    resp.setBody("{\"session_id\":\"" + session_id + "\"}");
    return resp;
});
```

**前端调用**：
```javascript
fetch('/api/sessions/new', { method: 'POST' })
  .then(r => r.json())
  .then(data => {
    console.log('新会话ID:', data.session_id);
  });
```

### 2. 发送消息接口

```cpp
addRoute("POST", "/api/chat", [&sessionManager](const HttpRequest& req) {
    auto params = req.parseJson();
    std::string session_id = params["session_id"];
    std::string message = params["message"];

    // 1. 检查 session 是否存在
    if (!sessionManager.sessionExists(session_id)) {
        HttpResponse resp;
        resp.setStatusCode(404);
        resp.setBody("{\"error\":\"Session not found\"}");
        return resp;
    }

    // 2. 将用户消息加入历史
    sessionManager.addMessage(session_id, "user", message);

    // 3. 获取上下文（包含历史）
    std::string context = sessionManager.getSessionContext(session_id, 5);

    // 4. 构建完整 prompt
    std::string full_prompt = context + "Assistant:";

    // 5. AI 推理
    std::string ai_reply = ModelManager::instance().infer(full_prompt, 128);

    // 6. 将 AI 回复加入历史
    sessionManager.addMessage(session_id, "assistant", ai_reply);

    // 7. 返回 AI 回复
    HttpResponse resp;
    resp.setStatusCode(200);
    resp.setHeader("Content-Type", "application/json");
    resp.setBody("{\"response\":\"" + ai_reply + "\"}");
    return resp;
});
```

**前端调用**：
```javascript
fetch('/api/chat', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    session_id: 'a3f5d8b2c1e9f4a6',
    message: '我叫什么名字？'
  })
})
.then(r => r.json())
.then(data => {
  console.log('AI回复:', data.response);
});
```

## 本节课用到的 C++ 知识

### 1. std::unordered_map - 哈希表

```cpp
std::unordered_map<std::string, Session> sessions_;
```

**为什么使用哈希表？**
- **O(1) 查找性能**：根据 session_id 快速定位
- **动态大小**：自动扩容
- **键值对存储**：session_id → Session 对象

**常用操作**：
```cpp
// 插入
sessions_[session_id] = Session(session_id);

// 查找
auto it = sessions_.find(session_id);
if (it != sessions_.end()) {
    Session& session = it->second;  // 找到了
}

// 删除
sessions_.erase(session_id);

// 遍历（C++17 结构化绑定）
for (const auto& [id, session] : sessions_) {
    std::cout << id << ": " << session.title << "\n";
}
```

### 2. std::chrono - 时间库

```cpp
// 获取当前时间戳（毫秒）
long long now = std::chrono::duration_cast<std::chrono::milliseconds>(
    std::chrono::system_clock::now().time_since_epoch()
).count();
```

**时间单位转换**：
```cpp
using namespace std::chrono;

auto now = system_clock::now();
auto epoch = now.time_since_epoch();

auto seconds = duration_cast<seconds>(epoch).count();
auto millis = duration_cast<milliseconds>(epoch).count();
auto micros = duration_cast<microseconds>(epoch).count();
```

### 3. std::mt19937 - 随机数生成

```cpp
std::random_device rd_;   // 真随机数种子
std::mt19937 gen_(rd_);   // Mersenne Twister 引擎
std::uniform_int_distribution<> dis(0, 15);  // [0, 15] 均匀分布

int random_value = dis(gen_);  // 生成随机数
```

**为什么用 mt19937？**
- **高质量**：周期长（2^19937 - 1）
- **快速**：比 rand() 更快
- **可复现**：相同种子产生相同序列（用于测试）

### 4. std::lock_guard - 自动锁管理

```cpp
void SessionManager::addMessage(...) {
    std::lock_guard<std::mutex> lock(mutex_);
    // 临界区：修改 sessions_
    sessions_[session_id].addMessage(...);
    // 离开作用域，自动解锁
}
```

**为什么需要锁？**
```
线程A: sessions_[id1].addMessage(...)  ┐
                                       ├→ 并发访问 sessions_（数据竞争！）
线程B: sessions_[id2].addMessage(...)  ┘
```

**lock_guard 的优势**：
- 构造时自动加锁
- 析构时自动解锁（即使抛异常也能解锁）
- RAII 机制保证线程安全

### 5. std::stringstream - 字符串流

```cpp
std::stringstream json;
json << "{"
     << "\"session_id\":\"" << session_id << "\","
     << "\"title\":\"" << title << "\""
     << "}";
std::string result = json.str();
```

**vs 字符串拼接**：
```cpp
// 方式1：字符串拼接（低效）
std::string json = "{";
json += "\"session_id\":\"" + session_id + "\",";
json += "\"title\":\"" + title + "\"";
json += "}";

// 方式2：stringstream（高效）
std::stringstream json;
json << "{\"session_id\":\"" << session_id << "\","
     << "\"title\":\"" << title << "\"}";
```

**stringstream 优势**：
- 避免频繁的字符串拷贝
- 支持格式化输出（setprecision、setw 等）
- 性能更好（特别是大量拼接时）

## 性能优化与最佳实践

### 1. 限制历史长度

```cpp
// 只保留最近 N 轮对话
std::string getRecentContext(int n_turns = 5) const {
    int start_idx = std::max(0, (int)history.size() - n_turns * 2);
    // 只从 start_idx 开始拼接
}
```

**为什么要限制？**
- **Token 限制**：模型 n_ctx 有上限（如 2048）
- **性能优化**：prompt 越长，推理越慢
- **相关性**：最近的对话通常更重要

**经验值**：
```
n_ctx = 2048: n_turns = 5-10（约 1000 tokens）
n_ctx = 4096: n_turns = 10-20（约 2000 tokens）
```

### 2. Session 过期清理

```cpp
void SessionManager::cleanupExpiredSessions(int timeout_minutes = 30) {
    std::lock_guard<std::mutex> lock(mutex_);

    auto now = std::chrono::system_clock::now();
    auto timeout_ms = timeout_minutes * 60 * 1000;

    auto it = sessions_.begin();
    while (it != sessions_.end()) {
        long long inactive_time = now - it->second.last_active;
        if (inactive_time > timeout_ms) {
            std::cout << "[SessionManager] Cleaning up session: "
                      << it->first << "\n";
            it = sessions_.erase(it);  // 删除并移动迭代器
        } else {
            ++it;
        }
    }
}
```

**定时清理**：
```cpp
// 在 main() 中启动定时器线程
std::thread cleanup_thread([&sessionManager]() {
    while (true) {
        std::this_thread::sleep_for(std::chrono::minutes(10));
        sessionManager.cleanupExpiredSessions(30);
    }
});
cleanup_thread.detach();
```

### 3. Session 数量限制

```cpp
std::string SessionManager::createSession() {
    std::lock_guard<std::mutex> lock(mutex_);

    // 限制最大 session 数量
    if (sessions_.size() >= MAX_SESSIONS) {
        // 删除最久未活跃的 session
        evictLRU();
    }

    // 创建新 session...
}

void SessionManager::evictLRU() {
    // 找到 last_active 最小的 session
    auto oldest = std::min_element(
        sessions_.begin(),
        sessions_.end(),
        [](const auto& a, const auto& b) {
            return a.second.last_active < b.second.last_active;
        }
    );

    if (oldest != sessions_.end()) {
        sessions_.erase(oldest);
    }
}
```

```
前端 → POST /api/sessions/new

前端 → POST /api/chat
       { "session_id": "abc123", "message": "我叫Alice" }
后端内部流程:
  1. addMessage("abc123", "user", "我叫Alice")
```

## 局限性与后续优化

### Server-12 的局限性

1. **内存存储**：
   - Session 存储在内存中，重启后丢失
   - 无法持久化对话历史

2. **重复计算**：
   - 每次推理都重新处理完整历史
   - 没有利用 KV Cache 加速

3. **无并发优化**：
   - 所有请求共享一个 ModelManager
   - 无法批处理多个请求

### 后续优化方向

1. **Server-13-KVcache**：
   - 引入 SessionContextPool
   - 利用 KV Cache 避免重复计算
   - 每个 session 有独立的 llama_context

2. **Server-13-Batch**：
   - 引入 BatchInferenceEngine
   - 多个请求并行推理
   - 充分利用 GPU/CPU 资源

3. **持久化存储**：
   - 将 Session 存入数据库（SQLite）
   - 用户可以跨设备访问历史对话

## 总结

### 核心要点
1. **SessionManager**：管理多个独立的对话会话
2. **Message 历史**：记录每轮 user/assistant 消息
3. **上下文拼接**：将历史拼接成完整 prompt
4. **线程安全**：使用 mutex 保护并发访问

### 技术栈
- std::unordered_map（哈希表）
- std::chrono（时间库）
- std::mt19937（随机数生成）
- std::lock_guard（线程安全）
- std::stringstream（字符串拼接）
