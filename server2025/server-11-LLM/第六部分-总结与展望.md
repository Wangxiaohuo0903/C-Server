## 6.2 Server-10到Server-11的进化

**核心理念**：Server-11不是从零开始的全新项目，而是**在Server-10基础上的渐进式升级**。我们保留了Server-10的所有核心功能，仅替换了Mock AI部分为真实的LLM推理。

让我们用表格总结两个版本的对比：

| 维度 | Server-10 | Server-11 | 进化 |
|------|----------|----------|------|
| **AI能力** | Mock（返回固定字符串） | 真实LLM推理 | 🚀 质的飞跃 |
| **推理引擎** | 无 | llama.cpp | ✅ 新增 |
| **模型** | 无 | SmolLM-360M-Q4 (259MB) | ✅ 新增 |
| **推理速度** | 即时 | ~8秒（30 tokens）| ⚠️ 牺牲速度换取真实性 |
| **内存占用** | ~10MB | ~300MB | ⚠️ 增加30倍 |
| **代码复杂度** | 500行 | 800行（主程序+封装） | ⬆️ 适度增加 |
| **依赖** | SQLite | SQLite + llama.cpp | ⬆️ 增加依赖 |
| **部署方式** | 本地编译 | Docker容器 | 🚀 标准化 |
| **可移植性** | 低（依赖系统环境） | 高（容器化） | ✅ 大幅提升 |
| **学习价值** | 网络编程基础 | AI系统集成 | 🚀 质的提升 |

## 6.3 后续改进方向

Server-11是一个教学项目，还有很多可以改进的地方。

### 6.3.1 短期改进（1-2周）

**1. 添加会话管理**

当前Server-11每次请求都是独立的，无法记住上下文。可以添加会话管理：

```cpp
// 当前实现
POST /infer {"prompt": "Hello"}
→ "Hi there!"

POST /infer {"prompt": "What's my name?"}
→ "I don't know your name."  // ❌ 忘记了前面的对话

// 改进后
POST /chat {"session_id": "user123", "message": "My name is Alice"}
→ "Nice to meet you, Alice!"

POST /chat {"session_id": "user123", "message": "What's my name?"}
→ "Your name is Alice!"  // ✅ 记住了！
```

**实现思路**：

```cpp
// 维护一个session map
std::map<std::string, std::vector<std::string>> sessions;

std::string chat(const std::string& session_id, const std::string& message) {
    // 1. 加载历史对话
    std::string full_prompt = "";
    for (const auto& msg : sessions[session_id]) {
        full_prompt += msg + "\n";
    }
    full_prompt += message;

    // 2. 推理
    std::string response = inference.infer(full_prompt, 50);

    // 3. 保存到历史
    sessions[session_id].push_back(message);
    sessions[session_id].push_back(response);

    return response;
}
```

**2. 流式响应**

当前Server-11等待所有token生成完毕才返回，用户需要等待8秒。可以改为流式返回：

```cpp
// 当前实现
POST /infer {"prompt": "Explain AI"}
→ 等待8秒...
→ 返回完整响应

// 改进后（Server-Sent Events）
POST /infer_stream {"prompt": "Explain AI"}
→ data: "AI"
→ data: " is"
→ data: " a"
→ data: " technology"
→ ...
→ 用户实时看到生成过程
```

**实现思路**：

```cpp
void handle_infer_stream(int client_fd, const std::string& prompt) {
    // 发送SSE头
    std::string header = "HTTP/1.1 200 OK\r\n"
                        "Content-Type: text/event-stream\r\n"
                        "Cache-Control: no-cache\r\n"
                        "\r\n";
    send(client_fd, header.c_str(), header.length(), 0);

    // 修改generate_tokens，每生成一个token就发送
    for (int step = 0; step < max_tokens; ++step) {
        // ... 生成next_token ...

        std::string sse_data = "data: " + token_text + "\n\n";
        send(client_fd, sse_data.c_str(), sse_data.length(), 0);
    }

    // 发送结束标志
    send(client_fd, "data: [DONE]\n\n", 14, 0);
}
```

**3. 支持更多采样策略**

当前Server-11只支持贪婪采样，可以添加：

```cpp
enum SamplingStrategy {
    GREEDY,        // 贪婪采样（当前实现）
    TOP_K,         // Top-K采样
    TOP_P,         // Top-P（Nucleus）采样
    TEMPERATURE    // Temperature采样
};

int sample_token(const float* logits, int vocab_size, SamplingStrategy strategy, float param) {
    switch (strategy) {
        case GREEDY:
            return argmax(logits, vocab_size);

        case TOP_K:
            return sample_top_k(logits, vocab_size, (int)param);

        case TOP_P:
            return sample_top_p(logits, vocab_size, param);

        case TEMPERATURE:
            return sample_temperature(logits, vocab_size, param);
    }
}
```

class ModelManager {
private:
    std::map<std::string, SimpleInference*> models;

public:
    void load_model(const std::string& name, const std::string& path) {
        models[name] = new SimpleInference(path);
    }

    std::string infer(const std::string& model_name, const std::string& prompt) {
        if (models.find(model_name) == models.end()) {
            throw std::runtime_error("Model not found: " + model_name);
        }

    }
};

**6. 请求队列和并发优化**

当前Server-11串行处理请求。可以添加请求队列：

```cpp
#include <queue>
#include <thread>
#include <mutex>
#include <condition_variable>

class RequestQueue {
private:
    std::queue<Request> queue;
    std::mutex mutex;
    std::condition_variable cv;

public:
    void push(Request req) {
        std::lock_guard<std::mutex> lock(mutex);
        queue.push(req);
        cv.notify_one();
    }

    Request pop() {
        std::unique_lock<std::mutex> lock(mutex);
        cv.wait(lock, [this] { return !queue.empty(); });
        Request req = queue.front();
        queue.pop();
        return req;
    }
};

// 工作线程
void worker_thread(RequestQueue& queue, SimpleInference& inference) {
    while (true) {
        Request req = queue.pop();
        std::string result = inference.infer(req.prompt, req.max_tokens);
        send_response(req.client_fd, result);
    }
}
```
